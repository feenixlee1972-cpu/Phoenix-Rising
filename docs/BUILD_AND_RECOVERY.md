# Phoenix Rises — Build & Recovery Record

## Master project
Repository: `feenixlee1972-cpu/Phoenix-Rising`

## Build
The Android build is generated by `.github/workflows/build-apk.yml` using Java 17, Android SDK 34, and Gradle 8.5.

The workflow produces two artifacts:
- `Phoenix-Rises-debug-apk` — installable debug APK when the workflow completes successfully.
- `Phoenix-Rises-complete-source-backup` — source/project/assets backup.

## Recovery
The source repository is the canonical working copy. The saved dashboard artwork/reference is the visual master. Do not replace the dashboard with a simplified design when making functional fixes.

## Functional rules
- Gold Mining: CAD payout only.
- Bitcoin Mining: BTC payout directly to a verified Bitcoin wallet.
- Other verified earnings: PayPal or Bank payout paths.
- A transfer must remain `REQUESTED`/pending until the connected provider confirms success.
- No provider credentials, wallet keys, bank credentials, or invented transaction confirmations belong in client-side code.

## Verification
Before calling a release finished, verify:
1. Android project compiles.
2. APK artifact exists.
3. Required web assets are packaged.
4. START/STOP survives Android WebView lifecycle/background suspension using persisted timestamps.
5. Agent range 51–70 is present.
6. Gold and Bitcoin mining screens are present.
7. Currency routing is correct: Gold=CAD, Bitcoin=BTC.
8. Payout requests validate destination and amount.
9. Source backup artifact is produced.
10. No claim of real provider success is made without provider confirmation.
